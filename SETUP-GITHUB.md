# One-click packs, built and hosted free on GitHub

1. Create a free account at github.com (if you have none).
2. Create a new **public** repository named `kayali-packs` (public repositories get the free 4-core, 16 GB build machines).
3. Upload everything in this kit to it (the `.github` folder included). On the web: Add file → Upload files, drag the kit's contents.
4. Open the **Actions** tab → "Build KAYALI packs" → **Run workflow**. Each country takes from minutes (Lebanon) to a few hours (Saudi Arabia).
5. When it finishes, the repository has a release called **packs** with every country's file and a `catalog.json`.
6. Send me your GitHub username. I put `https://github.com/<you>/kayali-packs/releases/download/packs/catalog.json` into KAYALI, so every user sees **⬇ Download** with one tap. It refreshes itself monthly.
